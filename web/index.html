ABOUT THE PROJECT

TURNING RACE DATA
INTO INSIGHTS.

Formula 1 Race Intelligence Dashboard is a data visualisation project focused on exploring motorsport analytics through interactive charts and graphical representations.

The project uses Tableau Public to present race-related information in an accessible format, making comparisons, patterns, and performance metrics easier to investigate.
